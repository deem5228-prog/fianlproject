3.1 factory fromJson() — แปลง JSON เป็น Object

🐍 Python

🎯 Dart
factory PredictionResult.fromJson( Map<String, dynamic> json) { return PredictionResult( predictedScore: (json['predicted_score'] as num).toInt(), rawScore: (json['raw_score'] as num).toDouble(), rgb: RGBColor.fromJson(json['rgb']), ); }

factory เป็น constructor พิเศษใน Dart ที่สร้าง object จากข้อมูล ในที่นี้ใช้แปลง JSON (Map) ให้เป็น PredictionResult การใช้ (json['predicted_score'] as num).toInt() คือการป้องกันปัญหาเรื่องชนิดข้อมูลตัวเลขจาก API

5.3 แปลง RGB → CIELAB

แปลงสเปซสีให้เหมือนกับการเรียก skimage.color.rgb2lab() ใน Python (เริ่มจาก Gamma correction → Linear RGB → XYZ (D65) → CIELAB)

Dart static Map<String, double> rgbToCielab(double r, double g, double b) { // sRGB to Linear final rLin = _srgbToLinear(r); // Linear sRGB to XYZ (D65) final x = (0.4124564 * rLin + ...) / 0.95047; // XYZ to CIELAB final l = (116.0 * fy) - 16.0; final a = 500.0 * (fx - fy); final bLab = 200.0 * (fy - fz); return {'l': l, 'a': a, 'b': bLab}; }

9.4 การวาดรูปเอง (CustomPainter)

การใช้ CustomPainter ใน Flutter เหมือนกับการใช้ matplotlib หรือ canvas ใน Python ที่เราเขียนโค้ดวาดเส้นหรือรูปทรงเรขาคณิตด้วย paint(Canvas canvas, Size size)

🧩 Path.combine ทำอะไร?
ในระบบเราต้องการให้มีแผ่นกรองมืดๆ (Dark overlay) ทับภาพ แต่เว้น "รูทะลุตรงกลาง" ที่สว่างชัดเจน เราใช้ Path.combine(PathOperation.difference, ... ) เพื่อเอาพื้นที่สี่เหลี่ยมทั้งจอ มาหักลบด้วยวงกลมตรงกลางออก
Dart class _CircleMaskPainter extends CustomPainter { @override void paint(Canvas canvas, Size size) { // 1. สร้าง Path สีดำแบบเจาะรูวงกลมตรงกลาง! final backgroundPath = Path()..addRect(Rect.fromLTWH(0, 0, size.width, size.height)); final circlePath = Path()..addOval(Rect.fromCircle(center: Offset(centerX, centerY), radius: radius)); // difference คือ สี่เหลี่ยมลบด้วยวงกลม final maskPath = Path.combine(PathOperation.difference, backgroundPath, circlePath); final darkPaint = Paint()..color = Color(0xA6000000)..style = PaintingStyle.fill; canvas.drawPath(maskPath, darkPaint); // 2. วาดเส้นขอบวงกลมสีส้ม final borderPaint = Paint()..color = Color(0xFFE8A020)..style = PaintingStyle.stroke..strokeWidth = 2.5; canvas.drawCircle(Offset(centerX, centerY), radius, borderPaint); // 3. กากบาทศูนย์กลางวงกลม (Crosshair) // ลากเส้นแนวนอน และ แนวตั้งตัดกันที่จุดศูนย์กลาง canvas.drawLine(Offset(centerX - 10, centerY), Offset(centerX + 10, centerY), borderPaint); canvas.drawLine(Offset(centerX, centerY - 10), Offset(centerX, centerY + 10), borderPaint); } }
