📝 final คืออะไร?
final ใน Dart หมายถึง "กำหนดค่าได้ครั้งเดียว แล้วห้ามเปลี่ยน" — คล้ายกับการไม่มี setter ใน Python property ครับ
required หมายถึง "ต้องส่งค่านี้มาเสมอ ห้ามขาด" (ถ้าไม่ส่ง = Error ตอน compile!)

3.1 factory fromJson() — แปลง JSON เป็น Object

🐍 Python

🎯 Dart
factory PredictionResult.fromJson( Map<String, dynamic> json) { return PredictionResult( predictedScore: (json['predicted_score'] as num).toInt(), rawScore: (json['raw_score'] as num).toDouble(), rgb: RGBColor.fromJson(json['rgb']), ); }

factory เป็น constructor พิเศษใน Dart ที่สร้าง object จากข้อมูล ในที่นี้ใช้แปลง JSON (Map) ให้เป็น PredictionResult การใช้ (json['predicted_score'] as num).toInt() คือการป้องกันปัญหาเรื่องชนิดข้อมูลตัวเลขจาก API

5.3 แปลง RGB → CIELAB

แปลงสเปซสีให้เหมือนกับการเรียก skimage.color.rgb2lab() ใน Python (เริ่มจาก Gamma correction → Linear RGB → XYZ (D65) → CIELAB)

Dart static Map<String, double> rgbToCielab(double r, double g, double b) { // sRGB to Linear final rLin = _srgbToLinear(r); // Linear sRGB to XYZ (D65) final x = (0.4124564 * rLin + ...) / 0.95047; // XYZ to CIELAB final l = (116.0 * fy) - 16.0; final a = 500.0 * (fx - fy); final bLab = 200.0 * (fy - fz); return {'l': l, 'a': a, 'b': bLab}; }

lib/screens/result_screen.dart หน้าที่ใช้แสดงคะแนน (1-15) โดยมี "Hero Score Card" เป็นไฮไลต์หลัก

ภายในหน้าประกอบด้วย:

  • Hero Card (Gradient Amber): แสดงผลลัพธ์คะแนนใหญ่ ๆ และคะแนนดิบ
  • RGB Card & CIELAB Card: แสดงตารางข้อมูลสีแต่ละแกนที่แปลงมา
  • Color Attributes: โชว์ค่า Chroma (C*) และ Hue (h°)

🔍 บทที่ 11 — หน้าจอ detail_screen.dart

lib/screens/detail_screen.dart คือหน้าที่โชว์ข้อมูลลึกซึ้ง (Technical/Scientific Information)

ประกอบด้วย 5 ส่วนสำคัญ (สร้างด้วย _buildCard):

  1. ผลคะแนนพัดสีไข่แดง (DSM Fan Score) พร้อมค่าดิบ
  2. ค่าเฉลี่ยสีปริภูมิ RGB (Mean RGB) - R, G, B
  3. ค่าสีมาตรฐาน CIELAB (CIE 1976 D65) - L*, a*, b*
  4. คุณลักษณะเชิงสี (Color Attributes) - Chroma, Hue Angle
  5. คำอธิบายทางเทคนิค - ระบุการใช้ Center Circular Mask 42% + Support Vector Regression
